# Contributing

Thanks for contributing to this Spring Boot microservices project (Java 25).

## Requirements

- JDK **25** only (see `.sdkmanrc`)
- Maven 3.9+ (or use `./mvnw` / `mvnw.cmd`)

## Build

```bash
./mvnw clean test
```

## Quality tools

CK, CPD, Checkstyle, Git, JaCoCo, OWASP-Dependency-Check, PIT, PMD, SpotBugs,
Static-DU-JaCoCo-composite, diff-cover — see `documentation/TOOLS.md`.
